# Sibinesh Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Before deployment

1. Put your resume in `public/resume.pdf`.
2. Add your email address in `src/App.jsx` by replacing `href="mailto:"` with your email.
3. Test the GitHub, LinkedIn and project links.
4. Run `npm run build`.
5. Push to GitHub and deploy on Vercel.

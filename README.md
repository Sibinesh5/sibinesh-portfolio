## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Sibinesh5/sibinesh-portfolio.git
```

Open the project folder:

```bash
cd sibinesh-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
